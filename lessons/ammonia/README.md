## 讀之前先記住三件事

1. **氨氮被「去除」不等於被「降解成氮氣」。** 氨氮可能變成硝酸鹽（還在水裡）、進入菌體或植物、或從水面揮發。要分得清楚，就要量總氮並做質量平衡（第 3、9 章）。
2. **pH 和溫度決定氨氮是 NH₄⁺ 還是 NH₃。** 這同時影響毒性、微生物活性、揮發與植物耐受度（第 1 章）。
3. **基因存在 ≠ 正在作用。** qPCR 與定序告訴你「誰在、有多少」，速率要靠化學量測（第 5、6 章）。
