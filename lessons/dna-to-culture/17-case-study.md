# 第 17 章　案例：把這套流程真的跑在一株基改紅酵母上

前面十六章講方法。這一章把方法用在一組**真實的、還沒發表的資料**上：一株 *Rhodotorula toruloides* 的野生株與基改株全基因體組裝，加上設計這株基改菌時用的 11,647 bp 構築序列。

目標很具體：**插進去的東西，和當初設計的一樣嗎？在哪裡？幾份？有沒有壞掉的？**

這一章值得讀的地方不只是答案，還有過程中踩到的兩個坑——它們都是會讓人得到「看起來很合理但完全錯誤」結論的那種坑。

## 17.1 手上有什麼

| 檔案 | 內容 |
|---|---|
| `Rt_WT.fasta` | 標示為野生株的組裝，37 contigs、21,585,995 bp、N50 1,255,393 bp、GC 61.30%、0 個 N |
| `A13_4.fasta` | 標示為基改株的組裝，33 contigs、21,290,051 bp、N50 1,259,054 bp、GC 61.47%、0 個 N |
| 構築序列 | 11,647 bp 環狀質體，GC 58.8%（從 Benchling 匯出） |

兩份組裝的品質都很好：N50 超過 1.2 Mb、完全沒有未知鹼基，是長讀定序的水準。GC 61.3% 與 *R. toruloides* 的文獻值一致。

**這一章所有的數字都由 `code/case_rt.py` 算出來**，結果存成 `code/case_rt.json`，圖直接讀那份 JSON。原始的三個檔案不在這個 repo 裡（是未發表資料），所以你重跑時要自己指定路徑：

```bash
python code/case_rt.py --wt WT.fasta --mut MUT.fasta --construct construct.fasta
```

## 17.2 第一個結果就不在預期內

![圖 17-1　兩份組裝比對的結論](figures/fig17-1-overview.png)

兩份組裝有 **99.836% 的 31-mer 共有**——確實是同一株菌。但是：

- 標示為「野生株」的那一份有 **12 個** α-farnesene 合成酶拷貝、2 處農桿菌 T-DNA border、一個 76 kb 的插入陣列。
- 標示為「基改株」的那一份，上述全部是 **0**。該 CDS 的 31-mer 在裡面的存在比例是 **0.00%**——不是「少了幾個」，是完全沒有。

這種結果不要急著下結論說哪一管錯了。合理的可能有兩個：**樣品或檔名在送驗、回傳、改檔名的某一步交換了**（最常見），或是**這一株在培養過程中把構築丟掉了**（串聯重複會同源重組，沒有選擇壓力時特別容易）。

**分辨方法很便宜**：對兩株各做一次 AFS 的 PCR 或 qPCR，引子用比對出來的 CDS 序列設計。在釐清這件事之前，後面所有的分析都只能說「帶有插入的那一份」，不能說「基改株」。

> 這是第 11 章「數據要能回溯」的實例。定序結果和實驗紀錄對不起來時，**要修正的往往是標籤，不是結論**——但你得先有能力發現它們對不起來。

## 17.3 怎麼找到它的：兩個差點讓人走錯路的坑

### 坑一：用 GC 當外來 DNA 的判準，差點整個漏掉

第一輪分析用的判準是「GC 偏離基因體平均 → 可能是外來 DNA」。這個判準在很多情況下有效，但這次**完全失靈**：

| | GC |
|---|---|
| 宿主基因體平均 | 61.3% |
| 蘋果原生的 AFS 基因 | 約 42% |
| **實際插進去的 AFS CDS** | **63.3%** |

因為這個基因**做過密碼子最佳化**，GC 已經被調到和宿主一樣高。用 GC 篩，它會被歸到「和基因體相近，可能是菌株間差異」而被忽略。

真正找到它的是三個條件並用：**連續的新增區段 ＋ 完整的 ORF ＋ 保守模體**。那個 576 aa 的蛋白質同時具備：

- 長度 576 aa，與蘋果 MdAFS1 相同 [1]
- 第 33 位有 **RRx8W**（`RRSANYKPNIW`），植物萜類合成酶的標誌性模體
- 第 326 位有 **DDxxD**，萜類合成酶的鎂離子結合位，位置也吻合

反過來，那些 GC 低到 32–43%、被標成「可能是外來 DNA」的區段，轉譯出來是 `KKKKKK`、`MEWNGMEWNG`、`GGGGGG`——低複雜度重複，而且兩株都有。**全是假陽性。**

> 教訓：外來 DNA 的判準不能只看組成。密碼子最佳化會把 GC 這條線索整個抹掉，而低複雜度重複會製造大量假陽性。

### 坑二：忘了記錄探針命中的是哪一股

取出 12 個拷貝做比對時，我一開始直接用 `contig[位置:位置+1728]` 截取。但探針命中的是**負股**，所以截到的是反向互補——結果每個拷貝都「有 313–383 bp 突變」，還「在第 81 個密碼子提前終止」。

全部是假的。改成依命中方向決定要不要取反向互補之後，真實結果是：**12 個拷貝裡 11 個與設計逐鹼基零差異**。

這個坑很容易踩，因為錯誤的結果看起來非常像真的（突變數量合理、終止密碼子的位置也合理）。**自己寫比對程式時，方向一定要當成資料的一部分記下來。**

## 17.4 構築上有什麼

![圖 17-2　構築的元件圖](figures/fig17-2-construct.png)

構築是一個標準的雙元載體：

- **T-DNA（LB 125 → RB 5,597，5,447 bp）**：兩個表現卡匣——啟動子 P1 ＋ AFS（576 aa）＋ nos terminator，以及啟動子 P2 ＋ 篩選標記（191 aa 的 GNAT 乙醯轉移酶，GC 70.8%，明顯做過真菌密碼子最佳化）。
- **骨架（5,597 → 11,647，6,050 bp）**：KanR、pUC／pBR 複製起點、ParA／RepA、絲胺酸重組酶。這些本來應該留在農桿菌裡。
- 兩個卡匣之間還留著 **nos promoter ＋ 完整的多選殖位**（SacII–BamHI–SmaI–KpnI–SacI–EcoRV–PacI–EcoRI），是 pCAMBIA 類載體沒清掉的殘跡。以後要在同一個構築再加基因，這段是現成的插入點。

**但是有一件事要特別提出來：兩個啟動子的身分不明。**

我把構築的每一段，用四種嚴格度（`asm5`、`asm20`、`sr`、`map-ont`）比對回沒有插入的那一份組裝。對照測試確認方法沒問題（宿主側翼 200/200 bp 完全對上），結果是：

**構築 11,647 bp 沒有任何一段來自這株紅酵母的基因體。**

所以 P1 和 P2 **不是這株菌的原生啟動子**，也不是 CaMV 35S、不是 nos promoter、不是 *A. nidulans* trpC（都逐條比對過）。它們可能來自另一種真菌、另一株紅酵母，或是合成啟動子。

這不是學術細節——**啟動子決定 AFS 什麼時候表現**。如果它是組成型，那麼第 6 章的氮限制階段裡 AFS 仍在表現，但乙醯輔酶A 正被油脂合成搶走；如果它受氮或碳源調控，分階段的設計就完全不同。

### 要送去 BLAST 之前，先把載體殘跡切掉

第一次切出來的「P1」有 1,216 bp，但前面 216 bp 其實是 **pUC／M13 的 lac 區段加上 HindIII、AscI 選殖位**：

```
…GGGTAACGCCAGGGTTTTCCCAGTCACGACGTTGTAAAACGACGGCCAGT  ← M13 -20 引子結合區
GCCAAGCTT GGCGCGCC  ← HindIII、AscI，真正的啟動子從這裡開始
```

帶著這段去 BLAST，命中的會是一整頁的選殖載體，真正的啟動子會被洗掉。**切乾淨之後的 P1 是 1,000 bp（構築 366–1,366），P2 是 816 bp（構築 3,374–4,190）。**

> 這是一個通用的實務點：**任何要送資料庫比對的片段，都先確認它不含載體骨架**。NCBI 有 VecScreen 可以自動檢查。

### 連不上資料庫時，能從序列本身看出什麼？（結論：看不出來）

教材的執行環境沒有對外網路，所以我退一步做了能在本機做的事：數出啟動子上幾個關鍵轉錄因子結合模體的數量，拿**宿主基因體隨機抽樣的 2,000 段同長度片段**當背景比較（程式 `code/promoter_scan.py`）。最關心的是 **GATA（AreA／Nit2）**——真菌氮代謝阻遏的總開關，如果啟動子受氮限制調控，這裡通常會有成簇的 GATA 位點。

| 模體 | P1 實測 | 宿主背景中位數 | 背景 ≤ 實測的比例 |
|---|---|---|---|
| GATA（AreA／Nit2） | **0** | 1 | 47.6% |
| GATA 成對（≤50 bp） | **0** | 0 | 96.3% |
| TATA box | 0 | 0 | 97.7% |
| CCAAT（Hap） | 0 | 0 | 51.2% |

**這個結果什麼都證明不了。** P1 沒有 GATA 位點，但宿主基因體裡隨機抓一段 1,000 bp，也有 47.6% 的機會一個都沒有。換句話說，觀察到 0 個完全在背景的正常範圍內——**既不能說它受氮調控，也不能說它不受**。

把這件事寫出來，是因為這種分析很容易被過度解讀。模體只有 5–6 bp，隨機序列本來就會出現；**沒有和背景比，任何模體數量都沒有意義**。這一節是一個「做了但沒有結論」的例子，而沒有結論本身就是結論——不要拿它去支持任何培養策略。

### 所以還是得做這兩件事

1. **BLASTn**（`blastn` 對 `nr/nt`，用切乾淨的 1,000 bp）→ 知道它是哪個基因的上游、來自哪個物種。
2. **不同 C/N 下的 RT-qPCR** → 不管 BLAST 說什麼，這才是「AFS 在限氮階段還有沒有在表現」的直接答案。文獻說某個啟動子是組成型，不代表在你的培養條件、你的插入位置、12 個串聯拷貝的情況下也是。

第 2 件事其實比第 1 件重要，而且它就是第 11 章說的「把實測數據餵回模型」——只是餵的是表現量而不是生長曲線。

## 17.5 染色體上的實際排列

![圖 17-3　76 kb 的串聯陣列](figures/fig17-3-array.png)

用「構築上唯一出現的 25-mer」當錨點逐鹼基追蹤，得到 19 段整合片段。為什麼不用一般的比對軟體？因為**串聯重複會讓比對器在重複單元之間跳動**，接合點的位置會變得不可信。錨點追蹤則能把每一個斷點定到單一鹼基。

結果：

- 陣列在 Contig3 的 943,094–1,019,311，共 **76,217 bp**
- 其中 **75,993 bp（99.7%）能逐段對回構築**——沒有來源不明的 DNA，也沒有宿主序列被夾進陣列中間
- **12 個 AFS 拷貝**，全部在負股、方向一致（典型的頭尾串聯）
- **單一插入位點**：在沒有插入的那一份組裝裡，陣列的左右側翼落在 Contig4 的 940,770–942,770 與 942,830–944,829，**中間只隔 60 bp**。沒有染色體重排。
- T-DNA border 附近的斷點落在構築 84–222 與 5,495–5,582，**剛好切在邊界內側幾十 bp**，正是農桿菌邊界切割的落點 [2]

這解開了一個謎：第一輪分析看到「重複單元約 5,385 bp」時，不知道那是什麼。拿到構築之後才知道——**5,385 bp 就是 T-DNA 本身**。

## 17.6 整合的不是整個質體

![圖 17-4　每個構築座標整合了幾份](figures/fd17-4-copies.png)

把每個構築座標在陣列裡出現的次數畫出來，圖形非常乾淨：

| 構築區間 | 內容 | 份數 |
|---|---|---|
| 222–2,928 | 啟動子 P1 ＋ AFS | **12** |
| 2,928–5,247 | AFS 末端、nos terminator、P2、篩選標記 | **11** |
| 5,247–5,495 | 終止子 | **12** |
| 5,582–8,956 | RB 外側、KanR、複製起點 | **2** |
| 8,956–9,785 | 骨架 ORF | **3** |
| 9,785–11,624 | ParA、重組酶 | **2** |

**T-DNA 進去 11–12 份，骨架只有 2–3 份。** 這正是 T-DNA 轉移機制應該產生的樣子：邊界之間的那一段被選擇性地送進去很多次，骨架是「順便」被帶進去的。

骨架被帶進去在農桿菌轉形很常見，但**要記在菌株紀錄裡**：這株菌的染色體上有 2–3 份細菌的 kanamycin 抗性基因與複製起點。做任何需要申報基改生物的事情時，這是要寫出來的。

## 17.7 壞掉的那一個拷貝

![圖 17-5　拷貝 ③ 的接合點](figures/fig17-5-junction.png)

12 個拷貝裡有 11 個和設計**逐鹼基零差異**。第 3 個不一樣，但它不是突變：

它只含構築 222–2,928，在 AFS CDS 的第 1,587 bp（第 530 個密碼子）處**直接接到骨架序列**（構築 8,956–9,374）。前 1,586 bp 與設計完全一致，之後讀出 11 個外來胺基酸就撞到終止密碼子 → **540 aa**（正常 576 aa）。缺掉的 C 端含萜類合成酶的 C 端結構域，這個拷貝不可能有活性。

這很符合 ATMT 串聯整合的機制：T-DNA 一條接一條進入同一個斷點，**最後一條常常只進去一半，接到骨架上**。它不影響另外 11 個。

→ **功能性拷貝數：11。**

## 17.8 轉進去這個基因，代謝上改變了什麼

![圖 17-6　轉進去一個基因，代謝上改變了什麼](figures/fig17-6-pathway.png)

AFS 催化的反應只有一個：**FPP（法呢基焦磷酸）→ α-farnesene ＋ 焦磷酸**。一條反應、一個酵素。但它插進去的位置是整個萜類代謝的分岔點，所以影響比看起來大。

### 它搶的是誰的東西

FPP 原本有三個去向，現在多了第四個：

| 去向 | 做什麼 | 能不能動 |
|---|---|---|
| **ERG9 → 角鯊烯 → 麥角固醇** | 細胞膜的固醇 | **不能剔除**（必需）。只能換成弱啟動子或可調控啟動子把它調降 |
| **GGPP → 類胡蘿蔔素** | 紅酵母的紅色色素 | 可以調降。調降同時釋出 FPP，而且 OD600 會變好量 |
| **蛋白質法呢基化** | 修飾 Ras 等訊息蛋白 | 量少，但必需 |
| **α-farnesene（新增）** | 你要的產物 | — |

更上游還有一個更大的競爭者：**油脂**。脂肪酸合成搶的不是 FPP，而是再上游的**細胞質乙醯輔酶A**——也就是 MVA 路徑的原料。對產油酵母來說這條路是它的本業，而且**氮限制（高 C/N）正是把通量推往油脂的開關**。這一點很關鍵，因為第 6 章的兩階段策略常常就是用氮限制來切換階段。

### 要付多少代價：化學計量算得出來

![圖 17-7　多做一個產物要付出什麼](figures/fd17-7-cost.png)

把 MVA 路徑的六個反應式逐步加總（程式在 `code/farnesene_path.py`，數字可以自己驗算）：

- **每 1 個 C5 單元（IPP）**：3 個乙醯輔酶A、2 NADPH、3 ATP，並丟掉 1 個 CO₂。
- **每 1 分子 α-farnesene**（＝1 FPP＝3 個 C5）：**9 個乙醯輔酶A、6 NADPH、9 ATP，丟掉 3 個 CO₂**。
- **碳的理論上限**：4.5 莫耳葡萄糖換 1 莫耳產物 → 碳產率 **55.6%**，質量產率 **0.252 g/g 糖**。這個上限只算碳，沒有檢查 ATP 與 NADPH 夠不夠，所以**實際產率一定更低**。

和油脂比較很有意思：

| | 乙醯輔酶A | NADPH | ATP |
|---|---|---|---|
| α-farnesene（C15） | 9 | **6** | 9 |
| 硬脂酸（C18，油脂） | 9 | **16** | 8 |

**兩條路線搶的是同一批乙醯輔酶A，但油脂多吃 2.7 倍的 NADPH。** 所以在這株菌裡，NADPH 的主要消耗者是油脂而不是你的產物；如果要搶 NADPH，該動的是油脂那一邊。

### 可以動的四個地方

1. **把 HMG1 拉高**。HMG-CoA 還原酶是 MVA 的限速步驟，文獻上提高倍半萜產量最常用的手段之一 [3]。
2. **調降 ERG9**。FPP 最大的去向，但不能關掉——用弱啟動子或可調控啟動子。
3. **調降類胡蘿蔔素**。釋出 FPP，順便讓 OD600 變好量。
4. **挑氮限制的時機**。限氮催油脂，會把乙醯輔酶A 搶走。這一點和啟動子的身分綁在一起（見 17.4）：**如果 AFS 的啟動子是組成型，限氮階段 AFS 還在表現，但原料被油脂搶走**，那這個階段對產物就是純粹的浪費。

這四個不要一次動兩個，也不要憑感覺動——這正是第 16 章要用 rhto-GEM 算生產包絡線的理由：模型可以先告訴你「調降 ERG9 到什麼程度，產物上升而細胞還長得動」。

### 三件會讓你量錯或做白工的事

1. **α-farnesene 會揮發**。不加十二烷等有機相覆蓋收集，量到的產量嚴重低估 [3]。
2. **萜類對細胞膜有毒**。高產菌株長得特別差時先懷疑產物毒性，不要一直調溫度和 pH。有機相覆蓋同時也有解毒作用。
3. **菌體是紅的**。這件事比看起來麻煩，下面單獨說。

### 為什麼稀釋救不了 OD600

很多人以為「稀釋 40 倍讓讀值回到 0.1–0.5 就沒問題了」。稀釋解決的是**另一個**問題。

這裡其實有兩個獨立的問題：

| 問題 | 原因 | 稀釋有沒有用 |
|---|---|---|
| **讀值不線性** | OD 太高時光被散射很多次，讀到的值比真實值低 | **有用。** 這正是稀釋要解決的事——把讀值拉回 0.1–0.5 的線性區 |
| **OD 換算成菌量的係數不對** | 紅酵母的色素與油滴改變了每個細胞的光學性質 | **沒有用。** 稀釋把散射和吸收**同時**除以 40，比值完全沒變 |

OD600 量的主要是**散射**不是吸收。類胡蘿蔔素（β-胡蘿蔔素、torulene、torularhodin）的吸收峰在 450–550 nm，在 600 nm 只剩尾巴——所以色素的**直接吸收**貢獻不大。真正會害你的是第二層：

- **色素與油滴改變了細胞的散射特性**。氮限制階段細胞塞滿油滴，折射率和大小都變了，**同樣 1 g 乾重的菌，OD600 讀出來就是不一樣**。
- 而且這個偏差**會隨培養階段漂移**：長菌期和產油期的 OD→乾重係數不同。一條在長菌期做的校正線，用到產油期就是錯的。
- 基改株和野生株的色素量也可能不同，**拿 OD 直接比較兩株的「生物量」是不成立的**。

所以要這樣做：

1. **稀釋照做**，目的是維持線性，不是為了修正色素。
2. **自己做 OD600 ↔ 乾重校正線**，而且**每個培養階段各做一條**（至少長菌期與產油期各一）。第 10 章的 `OD_TO_GDW = 0.35` 是大腸桿菌的示範值，**不能照抄**。
3. **乾重才是基準**，OD 只當線上代理指標，每批至少取 3–4 個點用乾重錨定。
4. 想降低色素的直接吸收，可以**改量 700 nm 或 750 nm**（色素在那裡幾乎不吸收）。這能減掉吸收那一項，但**減不掉油滴造成的散射變化**——校正線還是得做。
5. 順帶一提：OD600 與 OD750 的**比值**反而可以當作色素含量的粗略指標，想追蹤類胡蘿蔔素被調降了多少時很好用。

> **這一節是生化計量與文獻整理，不是模擬結果。** 反應式與輔因子化學計量是課本等級、可以驗算的；至於「調降 ERG9 能多拿多少 FPP」「11 個拷貝夠不夠把 FPP 抽乾」這種定量問題，要跑 rhto-GEM 才能回答（第 15、16 章）。

## 17.9 四種狀態：什麼時候產油、什麼時候產色素、什麼時候產 farnesene

![圖 17-8　四種狀態](figures/fig17-8-states.png)

上一節講的是「誰搶誰」，這一節講「什麼時候搶」。這三個產物不是同時發生的，它們被**不同的訊號**觸發——只要知道是哪兩個開關，就能推出四種狀態。

> **先聲明**：象限的邊界是**推論**，不是量出來的。下面的機制在文獻上是清楚的，但「你的菌在什麼 C/N、什麼溶氧下會跨過邊界」只有你自己的數據能回答。這一節要當成**一個可以檢驗的假說**，不是結論。

### 開關一：氮耗盡（產油）

產油的觸發不是「氮很少」，而是**氮耗盡這個事件**。機制很明確：

> 氮耗盡 → AMP deaminase 活化 → 粒線體 AMP 下降 → NAD⁺-異檸檬酸脫氫酶被抑制 → 檸檬酸累積並輸出到細胞質 → ATP-citrate lyase 切出乙醯輔酶A → 脂肪酸

這是產油酵母的預設行為，**不是故障**。重點是它是**事件觸發**：你在培養液裡測到氨氮歸零的那一刻，就是開關被按下的時刻。這也是第 5、6 章說「找轉折點」要盯的那個指標。

### 開關二：逆境訊號（產類胡蘿蔔素）

類胡蘿蔔素不是被氮限制直接觸發的，它是**抗氧化防禦**——靜止期、高溶氧、光照（尤其藍光）都會誘導。實務上它常常和油脂同時出現，但那是因為兩者都發生在培養後期，**不是同一個開關**。這點很容易搞混。

→ 直接的推論：**透光的搖瓶放在亮的地方，等於一直在誘導競爭者。遮光是零成本的事。**

### 把兩個開關交叉，就是四種狀態

| 狀態 | 條件 | 碳流向 | 對 farnesene |
|---|---|---|---|
| **專心生長** | 氮充足、無逆境 | 蛋白質、核酸、膜脂 | ★ 競爭最小 |
| **產油** | 氮耗盡、無逆境 | 儲存油脂，50–70% 乾重 | 乙醯輔酶A 被搶 |
| **產類胡蘿蔔素** | 氮還夠、但有逆境 | FPP → GGPP → 色素 | FPP 被分流 |
| **油脂 ＋ 色素** | 氮耗盡 ＋ 逆境 | 兩條都開 | 兩邊都被搶 |

### 一個違反直覺的推論

把三條放在一起看，**farnesene 是被兩邊夾擊的那一個**：上游的乙醯輔酶A 被油脂搶，下游的 FPP 被色素分流。而兩邊競爭都最小的狀態是「氮充足、活躍生長、遮光、無逆境」——也就是菌量還不高的時候。

**這代表經典的「先長菌、再限氮切換產物」兩階段策略，對 farnesene 很可能是錯的。** 限氮催的是油脂，不是你的產物。文獻上在這株菌做倍半萜（α-bisabolene，和 α-farnesene 一樣從 FPP 出發）走的路線是：**不刻意限氮，用饋料批次維持高細胞密度與持續的碳流，加十二烷覆蓋把產物一直拉走** [1, 3]。

這和第 6 章不衝突——第 6 章教的是**方法**，但切換的目標變數要換：對 farnesene 來說，要找的切換點可能是「什麼時候開始饋料、什麼時候加有機相」，而不是「什麼時候限氮」。

**但這整段推論有一個前提：啟動子的身分（17.4）。** 如果 P1 剛好是受氮調控的，上面就要反過來——限氮變成必要，只是要接受油脂的競爭。

### 培養前期就看到菌變紅了，還有辦法產 farnesene 嗎

有。但它是一個**警訊**，不是判決。

**第一，色素搶走的量比想像中少。** 把類胡蘿蔔素換算成 α-farnesene 的當量——用異戊二烯單元算，C40 色素是 8 個 C5、α-farnesene 是 3 個（程式 `code/farnesene_path.py`）：

| 類胡蘿蔔素含量 | 全部關掉，最多多拿 |
|---|---|
| 1 mg/g 乾重 | +1.0 mg/g |
| 3 mg/g 乾重 | +3.0 mg/g |
| 5 mg/g 乾重 | +5.1 mg/g |

巧合地，**大約是 1 比 1**。而同一時間油脂是 500–700 mg/g。所以如果你的目標產量遠高於幾 mg/g，色素根本不是瓶頸；要搶碳，該動的是油脂那一邊。（這是**上限**——真的關掉色素，釋出的 FPP 也不會 100% 流向產物，麥角固醇那條路會吃掉一部分。）

**第二，早紅的真正意義是「細胞已經感覺到逆境」。** 這才是要查的事：

| 可能原因 | 怎麼確認 | 怎麼處理 |
|---|---|---|
| 氮其實早就耗盡了 | 測殘餘氨氮／游離胺基氮 | 饋料補氮 |
| 光照 | 看培養箱／搖瓶擺放位置 | 遮光（鋁箔包瓶） |
| 溶氧過高 | DO 電極 | 降轉速或降通氣 |
| 產物或代謝物毒性 | 和不產物的對照株比生長 | 加十二烷覆蓋層 |
| 溫度或 pH 偏離 | 例行紀錄 | 回到設定值 |

**同一個逆境多半同時在扣你的生長和產量**，所以查原因的價值遠大於去改色素那條路。

**第三，不要只憑顏色判斷。** 紅酵母本來就是紅的，差別在「每克乾重有多少色素」。眼睛看到的是總量，而培養前期菌量低，看起來紅＝**單位含量高**，那才是訊號。要分辨只能量：丙酮萃取讀 450–490 nm，換算成 mg/g 乾重。

### 那加抗氧化劑可以把菌「推回」farnesene 嗎

這個想法很合理——色素是抗氧化防禦，給外源抗氧化劑應該能降低誘導。但**當成提高產量的手段，很可能沒用**，原因是上面那張換算表：

**就算抗氧化劑完美地把類胡蘿蔔素壓到零，你最多也只拿回 1–5 mg/g。** 花成本、增加下游純化的麻煩、冒風險，換這個數字不划算。

而且有幾個實際的風險：

- **抗壞血酸在有金屬離子時會變成促氧化劑**（Fenton 反應），可能反而製造逆境。
- **類胡蘿蔔素是細胞膜裡的抗氧化劑**。如果你用的抗氧化劑不會分配到膜（抗壞血酸是水相的），等於拆了防護卻沒補上——而萜類產物的毒性正是作用在膜上。要補的話 α-生育酚比較合理，因為它進得了膜。
- 抗氧化劑本身可能被當碳源代謝掉，或干擾你的分析。

**但有一個不同的理由值得試：減輕產物毒性、讓細胞撐久一點。** 這和「把碳搶回來」是兩個完全不同的機制，而且**要用不同的指標驗證**——看的是生長速率與存活，不是顏色。

怎麼便宜地測試：抗氧化劑 2–3 個濃度 × 有無十二烷，量生物量、類胡蘿蔔素（A450）、farnesene（十二烷相 GC-MS）。**如果色素降了但 farnesene 沒升，這個假說就死了**，而你也同時確認了競爭不在你以為的地方——這是很值得的負面結果。

順帶一提：**十二烷覆蓋層本身就是最有效的「解毒」手段**，因為它持續把有毒又揮發的產物移走。要先做這個，再談抗氧化劑。

### 用一次實驗把四個狀態確定下來

這正是第 7 章 DoE 該用的地方。最小的設計：**3 個 C/N（低／中／高）× ±十二烷覆蓋**，每個條件做時序取樣，每個時間點同時量：

| 量什麼 | 方法 | 為什麼非量不可 |
|---|---|---|
| **殘餘氮**（NH₄⁺ 或游離胺基氮） | 試劑套組 | **最關鍵**——定出開關按下的時刻 |
| 殘糖 | HPLC 或試紙 | 碳還有沒有 |
| 乾重 | 離心烘乾 | 基準，不要只信 OD（見 17.8） |
| 油脂 | 乾重 − 脫脂乾重，或 Nile red | 競爭者一 |
| 類胡蘿蔔素 | 丙酮萃取，450–490 nm | 競爭者二 |
| **α-farnesene** | **十二烷相 GC-MS** | 不加有機相，這個數字是假的 |
| AFS 轉錄量 | RT-qPCR | **直接回答啟動子受不受氮調控** |

把這七條曲線疊在同一條時間軸上，四個狀態的邊界就自己畫出來了。而且最後那一列會順便解決 17.4 留下的問題——**不用等 BLAST**。

這組數據的格式也正好是第 11 章要的：條件一張 CSV、量測一張 CSV。

## 17.11 這套分析能回答什麼、不能回答什麼

**能回答**：插入物的身分、位置、份數下限、序列正確性、有沒有骨架、接合點在哪裡、哪個拷貝壞了。

**不能回答**：

- **精確的拷貝數**。組裝會把高度相同的重複壓縮，12 是**下限**。要定量得把原始讀段比回單一拷貝算深度。
- **表現量**。多拷貝串聯很常發生基因沉默，12 份不等於 12 倍表現。要 RT-qPCR。
- **酵素活性**。要酵素活性測定或產物量測。
- **蛋白質的最終身分**。這個執行環境沒有對外網路，所有身分判定都靠模體與逐字比對已知序列。KanR、ParA、GNAT 都是**推定**，要用 BLASTp 確認。

## 17.12 把這套方法用在你自己的資料上

整套分析收在 `code/genome_tools.py`，四個步驟：

```bash
# 1. 組裝品質
python code/genome_tools.py stats WT.fasta MUT.fasta

# 2. 找出「只有其中一邊有」的序列
python code/genome_tools.py compare WT.fasta MUT.fasta --out novel.fasta

# 3. 看那些序列裡有沒有完整 ORF 與保守模體
python code/genome_tools.py orfs novel.fasta --prot candidates.faa

# 4. 有構築序列的話，直接把它對回基因體
python code/genome_tools.py construct construct.fasta MUT.fasta

# 5. 啟動子的模體掃描（要和宿主背景比才有意義）
python code/promoter_scan.py --construct construct.fasta --genome MUT.fasta
```

第 4 步是這一章的主角：它會輸出每一段整合片段、每個構築座標整合了幾份、以及 border 等已知元件的位置。**有構築序列和沒有構築序列，分析的品質差很多**——沒有它只能說「有個 5,385 bp 的重複單元」，有了它才能說「那是 T-DNA，骨架進去 2–3 份，第 3 個拷貝斷在第 530 個密碼子」。

所以：**做基改之前就把構築序列存好**，這是事後解讀定序結果最重要的一份檔案。

## 本章重點

- 定序比對的第一個產出常常是「**資料和紀錄對不上**」。這不是失敗，是這個分析最有價值的時候——但前提是你要能發現它。
- **GC 不能當外來 DNA 的唯一判準**。密碼子最佳化會讓插入的基因和宿主一樣高 GC。要用「連續新增區段 ＋ 完整 ORF ＋ 保守模體」三者並用。
- 自己寫序列比對時，**股向要當成資料記下來**。忘了這件事會產生看起來很合理、實際上完全錯誤的突變清單。
- 串聯多拷貝整合用一般比對軟體會在重複單元之間跳動；**用唯一 k-mer 當錨點逐鹼基追蹤**，才能把接合點定到單一鹼基。
- T-DNA 與骨架的份數差異（11–12 份 vs 2–3 份）本身就是轉形機制的證據，也是菌株紀錄裡該寫的事。
- **轉一個基因進去，改變的不只是多一條反應**：AFS 把 FPP 從三個去向搶成四個，上游的乙醯輔酶A 還要和油脂競爭。每 1 分子產物要 9 個乙醯輔酶A、6 NADPH、9 ATP，碳的理論上限 55.6%（0.252 g/g 糖）。
- 油脂每 9 個乙醯輔酶A 要 16 NADPH，萜類只要 6——**搶輔因子的是油脂，不是你的產物**。氮限制催油脂，所以分階段策略要和啟動子的調控性質一起決定。
- **送資料庫比對之前先把載體殘跡切掉**。我第一次切出來的「啟動子」前面 216 bp 是 pUC／M13，帶著去 BLAST 只會命中一堆選殖載體。
- **模體掃描沒有和背景比就沒有意義**。P1 一個 GATA 位點都沒有，但宿主基因體隨機 1 kb 也有 47.6% 的機會是 0——這個分析做了，但沒有結論，而沒有結論也要照實寫。
- **稀釋救不了 OD600**。稀釋修的是線性，不是 OD→乾重的係數；色素與油滴讓這個係數隨階段漂移，每個階段都要自己做校正線。
- **三個產物由兩個不同的開關決定**：氮耗盡催油脂，逆境與光照催類胡蘿蔔素。farnesene 被兩邊夾擊，競爭最小的反而是「氮充足、活躍生長、遮光」——所以經典的限氮兩階段策略對它可能是錯的。
- **菌變紅是警訊不是判決**。把色素全部關掉最多只換回 1–5 mg/g 的產物（同時間油脂是 500–700 mg/g），所以該查的是「為什麼有逆境」，不是急著去改色素那條路。加抗氧化劑同理——值得試的理由是減輕產物毒性，不是搶碳。
- 這一章能回答「在不在、在哪裡、對不對、幾份（下限）」，回答不了「表現量與活性」。後者要 RT-qPCR 與產物量測，也就是第 11 章要餵回模型的那些數據。
