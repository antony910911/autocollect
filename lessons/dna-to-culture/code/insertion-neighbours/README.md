# 插入點旁邊那兩個基因

那段外來 DNA 插進去的地方，是兩個基因中間的空地。兩個基因本身都**沒有被壓到**，
但右邊那個（`downstream.faa`，1,441 aa）的「開關區」被蓋掉了大半，只剩 39 bp 原生序列。

定序廠的註解對這兩個基因**完全沒有命中**——KEGG、GO、Pfam 三個資料庫都查不到。
所以這裡把它們的蛋白質序列抽出來，拿去 NCBI 查。

## 下游那個（`downstream.faa`）已經查過了

結果存在 `g_05721-blastp-nr.xml`（blastp vs clustered_nr，2026-10）。解讀：

```bash
python ../blast_neighbours.py g_05721-blastp-nr.xml --faa downstream.faa \
    -o ../blast_neighbours.json
```

**結論：功能還是不知道，而且那不是失敗。**

- 37 筆命中，**35 筆是 hypothetical／uncharacterized**。
- 唯二有名字的兩筆都不能用：`proteophosphoglycan ppg4`（低複雜度區造成的誤標）、
  `UDP-galactose transporter`（31% 相似、覆蓋 35%，接近背景雜訊）。
- 命中落在 9 個屬，**全部是紅酵母與近緣真菌**——釀酒酵母、黴菌、動植物、細菌都沒有。
  **這是譜系特有的基因，沒有模式生物的同源基因可以借名字。**

但它定下了三件事：

1. **這是真的基因**——四株紅酵母都有，相似度 82.6–96.1%，全長對齊。
2. **起始密碼子位置正確**——三筆同種命中都從對方第 1 個胺基酸開始對齊。
   所以「插入在起始密碼子前 39 bp」成立，**那段 DNA 在基因外面，不在裡面**。
3. **架構是「低複雜度前段 ＋ 保守核心」**——前 861 aa 的 P＋A＋S＋T 佔 46.9%，
   只有自己這一種還像；後 579 aa（862–1440）才是遠緣物種也保留的核心。
   第 859–883 有一段疏水序列，**疑似膜錨，但訊號弱（峰值 2.04），要用 DeepTMHMM 確認**。

細節寫在第 17.11 節。

## 還沒做的三件事

1. **查 Coradetti 2018 的適應度資料**（eLife 7:e32110）。那個全基因體 T-DNA 突變庫
   **就做在 IFO 0880**，和這裡用的參考基因體同一株。先把蛋白質比回 JGI 的
   `Rhoto_IFO0880_4` 拿到基因編號，再去查那篇的補充檔。**不用做任何實驗。**
2. **用結構找遠親**：HHpred、Foldseek 或 AlphaFold DB，**只拿第 862–1440 個胺基酸去比**。
   BLASTp 比字面，結構比折疊——字面看不出來的遠親，結構常常還看得到。
3. **上游那個 423 aa 的鄰居（`upstream.faa`）還沒查。** 同一套流程再跑一次。

## 怎麼查（在你自己的電腦或瀏覽器上）

1. 開 <https://blast.ncbi.nlm.nih.gov/Blast.cgi>，選 **blastp**。
2. 把 `.faa` 的內容整個貼進去。Database 選 `nr`（或 `clustered_nr`，比較快）。
3. 跑完按 **Download → Single-file XML**，存成 `<基因>-blastp-nr.xml`。
4. 用上面那個指令解讀。

> **要注意的兩件事**
> - 相似度高不代表名字可信。看到 ppg4、mucin、collagen、titin 這類名字，
>   先確認不是低複雜度區造成的——`blast_neighbours.py` 會自動標出來。
> - **全部都是 hypothetical 是一個結論，不是查失敗。** 它告訴你「學界也還不知道」，
>   而這通常代表這個基因是譜系特有的。

## 查到之後要回頭看什麼

如果它是**代謝相關**的（酵素、轉運蛋白），開關被動到就可能直接影響代謝，要列進實驗要量的項目。
如果是**調控蛋白**（轉錄因子、訊息傳遞），影響更廣但更難預測。
如果**功能不明或非必需**，就可以放下，專心處理拷貝數與前驅物競爭。

不管答案是哪一個，最直接的驗證都是同一件事：
**用 RNA-seq 比較兩株這個基因的表現量差多少**，以及**把兩株的生長曲線放在一起比**。
後者是第 19 章第一批實驗本來就會做的事。
