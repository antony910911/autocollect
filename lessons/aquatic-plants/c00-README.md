# 分區三導讀　硝化槽＋植體槽

你問的是：**有沒有人做硝化槽搭配植體槽的設計？**

有，而且至少有四種版本，分別餵不同的水：

| 版本 | 進料 | 成熟度 |
|---|---|---|
| 魚菜共生（aquaponics） | 養殖排水 | 最成熟，有商業規模的設計準則 |
| 沼液水耕 | 厭氧消化液 | 實驗室到中試，有明確的成功與失敗案例 |
| 尿液回收 | 分離尿液 | 中試到實場（瑞士 VUNA 等） |
| 酸性硝化 | 沼液（pH 約 3） | 實驗室，但解決了一個老問題 |

這個分區講：

- **為什麼要先硝化**（第 1 章）——三個理由，外加一個「只做一半比不做更糟」的坑
- **耦合式與解耦式**（第 2 章）——差別只在一條回水管，但那條管子決定了 pH 聽誰的
- **怎麼算**（第 3 章）——投餵量 → 氨氮 → 氧氣 → 鹼度 → 植栽面積，一條線算到底
- **誰做過**（第 4 章）——四個版本的實際結果
- **還能做什麼**（第 5 章）——九種延伸應用，以及一個共同的瓶頸

## 這個分區的數字

化學計量（需氧量、鹼度消耗）是**我們自己依硝化反應式算的**，不是查表值；
投餵率與 PTAN 係數來自文獻。全部在 [`code/sizing.py`](code/sizing.py)。
