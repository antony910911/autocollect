# 分區二導讀　別人已經做過什麼

第一分區講的是植物與氨氮的關係。這個分區講**已經做出來的東西**：

- 人工濕地是什麼、有哪幾型、氮在裡面走哪條路（第 1 章）
- 各種做法的單位面積去除速率，以及「我的水要多大一塊地」（第 2 章）
- 沼液這種高濃度廢水怎麼辦（第 3 章）
- 看到「氨氮去除 98%」時要先問的五件事（第 4 章）
- 台灣的法規、既有案例與外來種管理（第 5 章）

## 先回答三個常被問的問題

**廢水處理真的有人用水生植物嗎？**
有，而且不是新東西。1970–80 年代 NASA 就在做布袋蓮污水處理，美國聖地牙哥 1984 年就有每日約 3,785 m³ 的水生植物廠。孟加拉 Mirzapur 的浮萍塘從 1993 年運轉到現在，是這個領域最常被引用的實場案例。

**台灣有嗎？**
有一整群。新北大漢溪沿岸的新海、浮洲、打鳥埤、城林、鹿角溪人工濕地都在運轉，有公開的年度成效數字。

**效果如何？**
差異非常大。同一群濕地在同一年度，氨氮去除率從 44% 到 97% 都有；同一座濕地颱風前 98.9%、颱風後掉到 35.1%。**所以第 4 章整章在講怎麼讀這些數字。**
