# 文獻引用與查證

## 格式

參考文獻放每章最後，標題固定是 `## 參考文獻`，每筆一行、編號：

```
1. 作者 (年). 標題. *期刊*, 卷, 頁. https://doi.org/10.xxxx/xxxxx
```

內文用 `[1]`、`[1, 3]` 引用。

## CI 會做什麼

`lessons/_tools/check_refs.py` 把每一個 `https://doi.org/...` 丟到 Crossref，**核對標題與年份和文中寫的一致**。對不上就以代碼 1 結束，build 失敗。

所以：

- **不確定的文獻寧可不放 DOI**（只放網址，或完全不放連結），**也不要猜**。
  不放 DOI 的那一筆會被跳過，不會擋住 build。
- **作者名不被核對**，但不確定縮寫時就只寫姓氏加 `et al.`，不要自己編。
- **卷、頁不被核對**，但不確定就不要寫。

## 這個環境查不到全文

`curl` 被閘道擋（403），`WebFetch` 對期刊網站、NCBI 都 DNS 失敗。**只有 WebSearch 能用。**

所以每一個從搜尋結果拿到的數字，都要標註可信度：

| 等級 | 意義 |
|---|---|
| `abstract` | 摘要或結論裡明確寫出的數字 |
| `secondary` | 來自回顧文章或資料庫摘要的轉述，連摘要都沒核對過 |

把這些記在對應的 `code/*.py` 資料表裡（例如 `literature_terpenes.py`），讓讀者可以逐筆回查。

**然後在章節裡明講：「這一章的數字沒有一筆核對過全文，引用前請自己開全文核對。」**
這不是免責聲明，是給讀者的使用說明。

## 查證流程

1. **WebSearch 搜論文標題 ＋ 作者 ＋ 年份**，確認 DOI、期刊、卷期。
2. **交叉比對兩個來源**。數字不一致時（例如同一篇被引成 393.5 和 383.5 mg/L），
   **兩個都寫出來並說明不一致**，不要自己挑一個。
3. **同一篇出現兩個數字時**（例如摘要寫 2.2 g/L、結論寫 2.6 g/L），
   寫出來並註明「對應哪個條件沒查清楚，要看全文的 Table」。
4. **優先重用這個 repo 已經通過 CI 的文獻**。`grep -rn "doi.org" lessons/*/[0-9]*.md`
   可以看到所有已驗證的 DOI，直接複製整行最安全。

## 一個實際的教訓

第 17 章曾經寫「文獻走的是不刻意限氮」——查證後發現**沒有任何一篇直接測過 C/N 對產量的影響**。
可驗證的只有「高糖饋料批次 ＋ 十二烷覆蓋」和「削弱油脂通量提高 6–7 倍」。

**從「A 導致 B」和「C 提高 D」推出「不要做 A」是推論，不是文獻結論。** 寫的時候要分清楚，
並在章節裡標明哪一段是推論。
